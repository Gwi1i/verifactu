# 🧭 Playbook de Posicionamiento y Distribución Orgánica
## Estrategia de Visibilidad para Micro-Herramientas B2B y Software de Cumplimiento

> **Objetivo:** Conseguir tráfico orgánico calificado, posicionamiento en buscadores y ventas de software digital sin presupuesto publicitario, sin redes sociales personales y con cero horas de soporte comercial humano.

---

## 🏛️ 1. La Filosofía del Modelo: 'Free Diagnostic Hook + Paid Lifetime Utility'

El software tradicional SaaS suele fallar para creadores individuales porque exige:
* Atención al cliente continua y soporte 24/7.
* Custodia de bases de datos y alta responsabilidad legal (RGPD, custodia de certificados fiscales).
* Costes fijos mensuales de servidores y bases de datos.

### Nuestra Fórmula Probada:
1. **El Gancho Gratuito (Top of Funnel):**
   Una herramienta web 100% client-side (se ejecuta en el navegador del usuario). No requiere registro, no pide email, no guarda datos en servidor. Esto elimina la fricción y gana la confianza inmediata de técnicos y empresas.
2. **El Producto de Pago (Bottom of Funnel):**
   Un plugin o script descargable con **licencia comercial de pago único (29€ - 49€)** que resuelve el problema de forma permanente y automática en la infraestructura del cliente.
3. **La Pasarela Merchant of Record:**
   Gumroad o Lemon Squeezy actúan como revendedor fiscal, cobrando en moneda local, aplicando y liquidando el IVA europeo automáticamente, y transfiriendo beneficios limpios por SEPA al banco.

## 🔍 2. Estrategia SEO Técnico de Densidad Alta (Ranking sin Enlaces Iniciales)

Cuando una web nace en un dominio nuevo o subdominio gratuito (github.io), no tiene autoridad acumulada. Para que Google la posicione frente a competidores establecidos, aplicamos **la tríada técnica de indexación rápida**:

### A. La Tríada Schema.org (JSON-LD)
Los buscadores procesan código estructurado antes que texto libre. Cada herramienta debe incluir en su <head>:
* **WebApplication:** Declara la aplicación interactiva, requisitos de navegador y gratuidad.
* **SoftwareApplication:** Registra la versión Pro de pago (nombre, precio, moneda y enlace de compra).
* **FAQPage (El acelerador a Página 1):** Incluye de 3 a 5 preguntas y respuestas con los términos exactos que los usuarios buscan. Google usa este bloque para colocar la web en los módulos de *'Preguntas de los usuarios'* y *'Resultados enriquecidos'*.

### B. Posicionamiento por 'Long-Tail' Normativo y Códigos de Error
Los competidores grandes compiten por palabras genéricas muy caras (*'factura electronica'*, *'software erp'*). Nuestra estrategia ataca las búsquedas de máxima desesperación:
* Códigos de error oficiales de la ley (ej. *'Error 1109 AEAT'*, *'Error 1154 rectificativa'*).
* Nomenclatura exacta de decretos y órdenes (ej. *'Orden HAC/1177/2024'*, *'RD 1007/2023'*).
* Búsquedas de implementación para plataformas específicas (ej. *'woocommerce verifactu plugin'*, *'calcular hash sha256 verifactu'*).

### C. Red de Indexación Multibuscador (IndexNow)
No depender exclusivamente de la cola de rastreo de Google:
* Generar una clave IndexNow (.txt) en la raíz del proyecto.
* Lanzar una petición HTTP POST a https://api.indexnow.org/indexnow tras cada actualización importante. Esto envía una señal instantánea a Microsoft Bing, Yahoo, Yandex y buscadores asociados.

## ⚓ 3. 'Parasite SEO' y Anclaje en Plataformas de Alta Autoridad

Dado que no usamos redes sociales personales, nos apoyamos en la autoridad de plataformas que Google ya rastrea cada pocos minutos (Domain Rating > 90):

### A. Optimización del Repositorio de GitHub (DR 96)
El repositorio de código no es solo para guardar archivos, es un activo SEO clave:
* **About / Description:** Texto denso en palabras clave técnicas.
* **Website:** Enlace directo con protocolo https:// hacia la landing page.
* **Topics (Etiquetas):** Mínimo 5 a 8 etiquetas técnicas oficiales (ej. erifactu, eat, woocommerce, acturacion-electronica).
* **README.md:** Estructurado con títulos H1/H2, tablas de compatibilidad y enlaces bidireccionales hacia la herramienta web y el producto de pago.

### B. Registros de Paquetes de Código Abierto (Próximos pasos)
Publicar componentes de validación en directorios públicos oficiales:
* **WordPress.org Plugin Directory:** Si se publica una versión gratuita recortada del plugin en el directorio oficial de WordPress, se obtiene un enlace .org de autoridad colosal que rankea de forma permanente en Google.
* **Composer / Packagist (PHP) y PyPI (Python):** Si se libera una librería ligera de cálculo de hash, los directorios de paquetes generan páginas indexables automáticas.

## 📊 4. Embudo de Conversión en la Página (De Visitante a Comprador)

Para maximizar ventas sin hacer llamadas ni comerciales, la página debe seguir una estructura psicológica de 4 bloques:

1. **Cabecera y Propuesta de Valor Inmediata:**  
   Qué es, qué ley cumple y botón de descarga directa del producto.
2. **Matriz Comparativa vs Competidores:**  
   Poner en evidencia la debilidad del mercado tradicional:
   * Competidores: Suscripción de 15€-25€/mes (180€-300€/año), límite de facturas, datos en servidores ajenos.
   * Nuestra solución: **Pago único (29€)**, facturas ilimitadas, 100% privado en local.
3. **Herramienta Interactiva Gratuita (Linter / Validador):**  
   Demuestra en la práctica que el algoritmo es riguroso, testeado con vectores oficiales y funciona al instante.
4. **Guía Técnica y Preguntas Frecuentes (FAQ):**  
   Resuelve dudas legales, técnicas y de instalación, aportando el volumen de texto necesario para el rastreo de Googlebot.

## 📈 5. Protocolo de Monitoreo y Mantenimiento Periódico

Para saber cuándo una herramienta ha despegado sin dedicarle más de 5 minutos al mes:

| Frecuencia | Herramienta | Acción |
| :--- | :--- | :--- |
| **Día 1-3** | Google Search Console | Verificar propiedad, subir sitemap.xml y solicitar indexación prioritaria. |
| **Día 7-14** | Google Search Console | Revisar la pestaña **'Rendimiento ➔ Consultas'**. Identificar qué palabras clave están empezando a generar impresiones. |
| **Mensual** | Gumroad Analytics | Comprobar visitas a la pasarela y ratio de conversión (visitas vs compras). |
| **Semestral** | BOE / AEAT / Normativa | Comprobar si hay una actualización menor del reglamento oficial para actualizar el linter y mantener la vigencia. |

## 🚀 6. Checklist de Lanzamiento Rápido para Nuevos Nichos (Plantilla Replicable)

Para cualquier futura herramienta (ej. FacturaE B2B, Directiva de Accesibilidad, etc.), seguir este orden exacto:

1. [ ] **Identificar fricción regulatoria:** Seleccionar ley o estándar con fecha límite de obligado cumplimiento.
2. [ ] **Diseñar algoritmo canónico:** Crear script de validación contrastado contra ejemplos oficiales.
3. [ ] **Empaquetar plugin o ejecutable:** Crear el archivo .zip para la plataforma objetivo (WordPress, Shopify, Python, etc.).
4. [ ] **Montar Landing 100% Client-Side:** Validador web gratuito + banner de producto Pro + tabla comparativa.
5. [ ] **Inyectar Tríada Schema.org:** WebApplication + SoftwareApplication + FAQPage.
6. [ ] **Desplegar en GitHub Pages:** Repositorio público con descripción, topics y enlace web configurados.
7. [ ] **Dar de alta en Gumroad:** Producto digital a 29€-49€ con archivo zip y cobro directo por IBAN.
8. [ ] **Verificar en Search Console y enviar a IndexNow:** Solicitar rastreo inmediato en Google y Bing.
